# rlisp-engine v0.21.0 — детерминизм: прогон воспроизводится побитово

## Что нового с v0.20.0

- **Запись и воспроизведение прогона**: `--record` пишет seed, ввод по кадрам и
  hash каждого кадра; `--replay` сверяет кадр в кадр и называет первый
  несовпавший. Hash считается по фреймбуферу, а не по модели мира, поэтому
  совпадение цепочки означает «игрок увидел те же пиксели».
- **Живая запись из редактора**: запись включается с любого кадра (панель
  «Детерминизм» на вкладке «Консоль»), в файле остаётся `start N`.
- **Детерминированный ГПСЧ с явным контрактом**: `(random-seed n)`,
  `(random-int a b)`, `(random-range a b)`; seed начала прогона пишется в файл.
- **143 теста** (было 130): новый модуль `src/replay.rs` + `src/interp/rng.rs`.

## Зачем это нужно

Отладка игр — это «покажи, как ты это получил». До этого релиза повтор
невозможен: время кадра плавает, случайность идёт от системных часов, ввод
приходит из stdin. Теперь прогон — это файл: его можно приложить к баг-репорту,
и он либо воспроизведётся у всех, либо покажет номер кадра, где всё разошлось.

# rlisp-engine v0.20.0 — честная альфа, сохранения прогресса

## Что нового с v0.19.0

- Спрайты без чёрных подложек: per-texel альфа (alpha-test в opaque,
  блендинг в прозрачном проходе) — демоны/пикапы РУИНЕРА выглядят как
  в классических шутерах.
- `save-table`/`load-table`: JSON-сохранения игр без зависимостей;
  РУИНЕР хранит рекорд очков и уровень в `saves/ruiner.json`.
- Звук: шаги при движении, рыки демонов в погоне.

## Быстрый старт

```bash
tar -xzf rlisp-engine-v0.20.0-linux-x64.tar.gz && cd rlisp-engine-0.20.0
./rlisp-engine --script lisp/main_ruiner.lisp
```

Экспорт игры одним файлом:
```bash
python3 scripts/export_game.py --game assets/lisp/main_ruiner.lisp \
  --title "РУИНЕР" --out ruiner.html
```
